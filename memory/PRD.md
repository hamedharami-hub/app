## Architecture
- Existing Vite + React 18 + TypeScript + Firebase app copied into `/app/frontend` (upstream base commit 612a061). Supervisor runs `yarn start` → Vite on :3000. FastAPI backend in `/app/backend` is unused.
- Dev-only QA harness: `/dev-preview/pharmacy.html?view=scenario|products&lang=en|fa` (fictional user, not in prod build).
- Pharmacy data is generated by `scripts/buildCompletePharmacySeedData.mjs` from the Pharmacy repo pinned at 5b4f7d2 (reference checkout at `/root/pharmacy`).
